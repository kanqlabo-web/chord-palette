# 引き継ぎ：コード進行パレット（コード進行を学ぶスマホ向け Web アプリ）

別のセッションで続きをするときは、最初にこのファイルを読んでください。

## 場所
- GitHub: `kanqlabo-web/chord-palette`（GitHub Pages で公開）
  - いつもの版: https://kanqlabo-web.github.io/chord-palette/ （`index.html`）
  - 試作版: https://kanqlabo-web.github.io/chord-palette/beta/ （`beta/index.html`）
- 本体のソース: `tools/chord-palette.src.html`
  - `index.html` は「`tools/hdr.txt` ＋ ソース ＋ 閉じタグ」で作る。**直すのはソースだけ**（index.html を直接直さない）
- 音源: `snd/*.json`（WebAudioFont の音を mp3 にして base64 で入れたもの）
  - 楽器は `{ "音の高さ": [ {lo,hi,op,ct,ft,ls,le,sr,f} ] }`、ドラムキットは MIDI のノート番号ごと
  - 足りない音は `git clone --filter=blob:none --no-checkout --depth 1 https://github.com/surikov/webaudiofontdata` → `git checkout HEAD -- sound/<ファイル>` で1つずつ取れる（raw.githubusercontent.com は使えないことが多い）

## 作業の流れ
1. clone: `git clone --depth 1 https://github.com/kanqlabo-web/chord-palette`
2. 手元で確認: リポジトリの直下で `python3 -m http.server 8765` → Playwright（`tools/t*.js`）で `http://localhost:8765/`（試作版は `/beta/`）を開く
   - サーバーはターンをまたぐと止まることがある。止まっていたら起動し直す
3. 公開: `bash tools/deploy.sh "コミットメッセージ"`
   - 版数を1つ上げて日付を入れ、index.html と beta/index.html を作り、構文チェックして push する
   - コミットに付ける行は `COMMIT_TRAILER="..." bash tools/deploy.sh "..."` で渡す
   - 版数は index.html の今の版数＋1（浅いクローンでもずれない）
   - gh のログインはできないことが多いので、Pages の完了待ちはしない。github.io もこの環境からは開けないことが多い
4. 試作版だけ変えたいとき: `tools/build_beta.sh` の中で beta.html に変更を当てる（保存データのキーは `cpbeta-`、音源は `../snd/`）。OK が出たらソースへ移す

## 確認用の道具（tools/）
- `mid.py` / `nd.py` / `dr.py`: MIDI の中身を小節ごとに書き出す（`python3 tools/nd.py ファイル.mid`）
- `tsty.js`: 全スタイルを鳴らしてエラーがないか
- `tallsty.js`: 全スタイルの音を JSON に書き出す（変更前後の比較用。ギター系・ロックなどは毎回少しランダムに変わる）
- `tbal.js`: バラード（ballade.mid と同じコード）を小節ごとに書き出す
- `tpar.js`: 通常モードのバラードと、PRO でマイパターンに取り込んだものが同じ音になるか
- `torn.js` / `trand.js`: 飾りの出方（いろいろな進行・ランダムな進行）、飾りが2音同時に鳴らないか
- `tvoic.js`: 右手の和音のはしが半音でぶつかる形がないか
- `ted.js`: PRO のパターン編集画面が開けるか
- `tcity.js`: シティポップ（Am・Em・F・C）の音
- `terr.js`: 開いたときのエラーだけ見る

## 決まりごと（ユーザーとの約束）
- 返事は丁寧語（です・ます）。短い前置き＋見出し付きの箇条書き。絵文字は使わない（アプリの UI もベクターのアイコン）
- アーティファクトは作らない。GitHub への push は確認なしでよい
- **通常モードでできることは、必ず PRO（マイパターン）でも同じものを作れるようにする**（取り込むと鳴り方が同じになること。`tpar.js` のように確かめる）
- **独自の機能を足すときは、先にユーザーに申請する**（ユーザーが「実装してかまわない」と言った範囲は除く）
- 名前・説明は、楽器にくわしくない一般の人にわかる言葉で（作業用の名前や MIDI のファイル名を画面に出さない）
- 使わなくなったもの・わかりにくくなったものは整理する（聴き比べ用の候補などを残さない。古い保存データは別名で置きかえる）

## 演奏データのしくみ
- コード楽器のパターン（`ARPS`）のイベント = `[マス, 行[], 長さ, 強さ, 方向, 飾り, (nx用3つ), オクターブ, 鳴らす条件]`
  - マスは16分（1小節16マス）。小数も使えるが、PRO の取り込みでは整数に丸まる
  - 行: 0=左手根音 4=左手5度 5=左手8度 1〜3=右手 下・中・上 9=右手 4音目 6〜8=アクセント（右手＋12） 'd1'〜'd10'=メロディ行
    - 右手 4音目: 4音のコードは4つ目の音。3音のコードでは、同時に「右手 下」を弾いていないとき（分散）だけ「右手 中＋12」
  - 飾り: fall（フォール） up（1つ上の和音の音） scoop（しゃくり） nx（次のコードへ音階でつなぐ）
    nt / ntd / ntu（次のコードのいちばん上の音／その1つ下／1つ上）、刺繍音（dn dn2 su su2 cd cu dnr upr grc grs trl p0 pu pd）
  - オクターブ（e[9]）: ±12。鳴らす条件（e[10]）: step（上の音の動きが小さい・上がる） down（大きく下がる：長3度以上） same（同じ） move（同じでない）
- 場面 `sit`: bar（1小節。2つなら交互、4つなら4小節ひとまとまり） bar3（3拍） halfA（前半2拍） halfB（3拍目から） beat（1拍） push（食い）
  - 場面のないパターンには、1小節の弾き方から自動で作る（autoScenes）
- マイパターン（PRO）は `state.myArps` などに保存し、`rebuildMy()` で ARPS に入れる。取り込み（`newMy`）は ARPS からマイパターンへ
  - 編集画面では同じ行の音は重ねられない（重なると前の音が切られる）。組み込みのパターンもこの形で書く
- 楽器2（コード2）は `withPart2()` で状態を入れ替えて同じ処理で鳴らす

## 主なしくみ（音の決め方）
- 和音の形（`chordNotes` / `voiceFor`）: 前の和音から近い形を選ぶ。真ん中の高さ（パターンの「右手の和音を置く高さの好み」でずらせる）から離れすぎない
  - 右手のいちばん上・下の音がとなりと半音でぶつかる形（FM7 の A C E F など）は選ばない。どうしても無理なときだけ、ベースと同じ音を右手から抜く
  - 同じ形のコードが半音・全音で動くときは平行移動。2音の刻みは半音でぶつからないようにする。内声は弱めない
- 音域は楽器ごとの絶対値（PRO のスライダー）。通常モードはスタイルごとの値（`lhOff` など）
- メロディの補正: キーの外の音を含むコードだけ。借りてきたコード（同主調）では同主短調の音階で
- 今のコードの音階（`chordScaleOf`）: 飾り・つなぎの音はここから選ぶ
  - キーの中のコード → キーの音階、借りてきたコード → 同主短調
  - キーの外の長三和音・属7 → 解決先（4度上）への部分転調（次が短調なら和声的短音階）。例: C のキーで E7→Am なら G は鳴らさない
  - 減和音 → 半音上の和声的短音階、m7(♭5) → 全音下の自然短音階
- 飾り「次のコードの上の音」系（`ornPitch`）: 次のコードを食うとき・次のコードがないときは入れない。隣の音まで増2度になるときは入れない
- 1周で止めるとき、食う曲は食いのタイミングで締める
- 左右の広がり（スタイルの wide）: 弦楽器は交互、鍵盤楽器は低い音ほど左、ほかはまん中
- ホルンなど tie のパターン: 同じ高さが続いたら弾き直さずにつなぐ

## スタイルで覚えておくこと
- バラード: ballade.mid（F のキー・テンポ80・ピアノだけ）から作った。左手はベースの音1つ（G2〜F♯3）、1拍目に和音、1拍裏から8分で分散、4小節目だけ1オクターブ下で上がる
  - 飾りは8分が基本、16分2音は2小節に1回。小節の途中でコードが変わる前は入れない。条件は上の音の動き（MIDI の分析から）
  - PRO で同じものを作るときは、左手の音域を G2 からにする
- ボサノバ: クラベスの「ポクポク」（2小節：1小節目 2拍・3拍裏 ／ 2小節目 1拍・2拍裏・4拍）＋3拍目に弱いスネア。ドラムキットの音源にクラベス（MIDI 75）を入れてある
- 壮大: 弦楽器の合奏＋ホルン（同じ音はつなぐ）。音量は コード1・コード2 1.1・ドラム0.25・ベース0.75
- アニソン: 上もの（コード2）なし

## 保留中・これからのこと
- **PRO 画面の整理（ユーザーが一時中止）**: メイン画面は通常モードと同じく伴奏を1行にまとめ、タップで DAW 風の画面（楽器ごとの行、横スワイプで音量・M/S・パン・リバーブ）を開く案。楽器の複数追加・パン・リバーブ・名前と色の変更も入れる予定だった。再開するときはユーザーに確認してから
- バラード: 3小節目（B♭/D）などで、和音の形が MIDI と違う（MIDI はベースの音を右手のいちばん下に重ねる）。そのため出る飾りも MIDI と変わる小節がある
- ギターの押さえ方（guitarShape）では、まれにはしが半音でぶつかる形が残る（Bm(M7) など）

## 追記（前のセッションからの補足）

### シティポップ（citypop.mid・brass2.mid から）
- ドラム: citypop.mid の強さをそのまま（`M16({マス:MIDIの強さ})`、dyn 2）。4小節目のフィルの最後でクラッシュするので、次の小節の頭のクラッシュはなし（`crash0:false`）
- ドラムの音: `cityDrum()`（タオルでミュートしたような乾いた音）。`KIT_GAIN.city` で音ごとの大きさを調整
- エレピ（`cityep`）: ルート・3度・7度の形（shell）。メロディ行のフレーズの下に、半音でぶつからない高さで置く。フレーズはコードより少し大きく
- エレピの音（`epDrive`）: 強く弾いた音。3.5kHz より上を取り出して足す「キラキラ」の枝あり
- ブラス（`brassobb`）
  - 1小節目へ食うとき「プァー↘」（3マス＋フォール）、2小節目へ食うときは短く
  - 2小節目は2マス目の「パッ」＋次のコードへのつなぎ。3拍のコード（bar3）はユーザーのスケッチどおり
  - 3音以上の「パー」はテンションのまま。2音の刻みだけ半音対策
- 通常モードの音域: エレピ 右手・左手 −3、ブラス 右手 −3（スタイルの `rhOff` など）

### ファンキー・レゲエ
- ファンキー: クラビネットの16分（`clavfunk`）＋ブラスのキメ（`brasshit`、しゃくり・フォール・次のコードへのつなぎ）
- レゲエ: オルガンのバブル（`skank`）

### PRO で使える主な設定（通常モードの再現用。足したら PRO にも出す）
- 食いの設定
  - 食う小節を「2小節目に入る時だけ」にする（`push2nd`）
  - 食って入った小節でも、頭の左手（根音・5度）は弾く（`pushKeepLH`）
- 音の高さ・形の設定
  - メロディ行の高さ（`melOct`）
  - 4音以上のコードのルートを省く（`noRoot`）
  - メロディをよける（`avoid`）
  - ギターの和音の形＝ボサノバのバレーコード（`bossaV`）
- リズムの設定
  - 16分で軽くハネる（`swing16`）
  - 人間っぽく揺らす（`loose`）
- 編集画面: 編集モード／選択モード（どちらも複数選択）、音ごとの長さ（1・半・4分の1マス）
- 音域: 楽器ごと（コード・コード2・ベース）の絶対値。スライダーで「いちばん下の音〜1オクターブ」を選ぶ（`rhLo` など）

### 作業の注意
- **1行の中に `// コメント` を差し込むと、その後ろのコードが全部コメントになる。** 以前これで弦楽器とアコギの設定（`INST_FX`）が消え、シンセ音になった。直したあとは `node --check` に加えて、実際に音色が鳴るかも確かめる
- **ほかのセッションが同じリポジトリを同時に直していることがある。** 作業の前と push の前に `git pull` する
- ソースは1行がとても長い。全体を読まず、`grep -n` で探して必要な行だけ見る（トークンの節約にもなる）
- ユーザーは PRO の編集画面のスクリーンショットで形を伝えてくる。マスの位置は「グリッドの幅 ÷ マス数」で、音の左端から読む。印の種類で飾りがわかる
  - 下向きの三角：下へ動く刺繍音
  - 上向きの三角：上へ動く刺繍音
  - 点線のふち：次のコードへつなぐ
  - 右上の斜線：フォール
- 参考にした MIDI（citypop.mid、brass2.mid、okesutora.mid、ballade.mid、ipanema、イエス様が〜（ボサノバ）など）はリポジトリに入っていない。もう一度必要ならユーザーに送ってもらう
- 「構造（構想）だけ教えて」と言われたときは、作らずに案だけ出す

### まだ気をつけたいこと（起きうる不具合）
- 通常モードの音域 −3 は「範囲をずらす」ので、キーによっては1オクターブ下がる（キー D♭ のエレピなど）。低すぎると言われたら、そのキーだけの問題か確かめる
- 平行移動が続くと、範囲から外れていく
- フィルは4小節ごとなので、3・5・6小節の進行では切れ目とずれる
- 2拍ずつ食う進行では、せわしなく聞こえることがある
