# ベータ版（beta）だけの部品

ここには「通常版（tools/src/）と違うファイル」だけを置きます。

- 同じ名前のファイル（例: `js/04-audio.js`、`style.css`、`body.html`）を置くと、ベータ版ではそちらを使います
- 新しい名前のファイル（例: `js/07-daw.js`）は、ベータ版にだけ足されます（js は名前の順に読み込みます）
- OK が出たら、そのファイルを tools/src/ へ移し、ここから消します
- ベータ版の保存データのキーは `cpbeta-`、音源は `../snd/`（index.html の CP_CONF で渡します）
