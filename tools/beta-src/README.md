# ベータ版（beta）だけの部品

ここには「通常版（tools/src/）と違う所」だけを置きます。ほかは通常版をそのまま使います。

- CSS は `beta.css` に、ベータ版だけの指定を書きます。通常版の `style.css` のあとに読むので、同じ指定なら beta.css が勝ちます
- JS は新しい名前のファイル（例: `js/11-paths.js`）を足します（通常版の JS のあと、名前の順に読み込みます）。通常版の関数を変えたいときは、そのファイルで同じ名前の関数を書き直します
- 通常版と同じ名前のファイル（`style.css`・`js/03-ui.js` など）を置くと丸ごと差しかえになり、通常版の直しが届かなくなります。build.py が警告を出すので、できるだけ使わないでください
- OK が出たら、その部分を tools/src/ へ移し、ここから消します
- ベータ版の保存データのキーは `cpbeta-`、音源は `../snd/`（index.html の CP_CONF で渡します）
